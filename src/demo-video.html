Encoding and delivery

The source and existing compact version were not re-encoded. Encode time covers processing; request times include delivery and vary with network and location. These are single-client measurements, not time to first frame.

Verified files are stored in R2 and served through Cloudflare with byte-range seeking. A stored-file cache hit is not proof of a geographic CDN edge hit. Playback uses a completed file; encoding is not streamed to the player.
